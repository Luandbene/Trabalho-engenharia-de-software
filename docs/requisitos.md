# Requisitos do Sistema

## Requisitos Funcionais
RF01 - O sistema deve permitir adicionar tarefas.
RF02 - O sistema deve permitir remover tarefas.
RF03 - O sistema deve permitir marcar tarefas como concluídas.
RF04 - O sistema deve listar todas as tarefas cadastradas.

## Requsitos não funcionais
RNF01 - O sistema deve possuir interface simples e intuitiva.
RNF02 - O sistema deve funcionar em navegadores modernos.
RNG03 - O Sistema deve responder rapidamente as ações do usuário
